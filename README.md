# Dependency Visualizer

Инструмент визуализации графа зависимостей для менеджера пакетов.

## Описание

Программа предназначена для анализа зависимостей программных пакетов
и последующего построения графа их связей.

Проект разрабатывается на Python без использования готовых
менеджеров пакетов и библиотек для получения зависимостей.

## Структура проекта

- src/ — исходный код программы.
- tests/ — автоматические тесты.
- README.md — описание проекта.
- .gitignore — исключения для Git.
- run.sh — запуск программы в Linux и macOS.
- run.bat — запуск программы в Windows.

## Запуск

Пример:

python3 src/main.py --package express --repo https://registry.npmjs.org --repo-mode remote --version 4.18.2

## Доступные параметры

- --package — имя пакета.
- --repo — URL или путь к репозиторию.
- --repo-mode — режим работы (remote или local).
- --version — версия пакета.
- --output — имя выходного изображения.
- --ascii — включение ASCII-дерева.
- --filter — фильтрация пакетов.

## Тестирование

Запуск тестов:

python3 -m unittest discover -s tests -v
