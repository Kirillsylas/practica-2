
# Dependency Visualizer

Инструмент визуализации графа зависимостей для менеджера пакетов npm.

## Описание

Программа получает информацию о зависимостях JavaScript-пакетов
из npm Registry или локального тестового JSON-файла.

Проект написан на Python без использования готовых менеджеров
пакетов и сторонних библиотек для получения зависимостей.

## Структура проекта

- src/ — исходный код программы.
- tests/ — автоматические тесты.
- test_repo.json — тестовый репозиторий.
- README.md — описание проекта.
- .gitignore — исключения Git.
- run.sh — запуск macOS и Linux.
- run.bat — запуск Windows.

## Параметры программы

- --package — имя пакета.
- --repo — URL или путь к репозиторию.
- --repo-mode — режим работы (remote или local).
- --version — версия пакета.
- --output — имя выходного изображения.
- --ascii — режим ASCII-дерева.
- --filter — подстрока для фильтрации пакетов.

## Запуск

Пример удаленного репозитория:

python3 src/main.py --package express --repo https://registry.npmjs.org --repo-mode remote --version 4.18.2

Пример локального репозитория:

python3 src/main.py --package express --repo test_repo.json --repo-mode local --version 4.18.2

## Тестирование

python3 -m unittest discover -s tests -v

## Этапы разработки

### Этап 1
Создание CLI-приложения и настройка параметров.

### Этап 2
Получение информации о прямых зависимостях npm-пакетов
из удаленного или локального репозитория.
